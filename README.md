# جنان | Civil Site Coordination

منصة خفيفة للتنسيق اليومي بين المهندس الاستشاري ومهندس المقاول في مشروع جنان.
تعمل من رابط واحد على الجوال والتابلت والكمبيوتر، وتُثبَّت كتطبيق على الشاشة الرئيسية، وتحفظ العمل عند انقطاع الإنترنت.

## ما الذي تقدمه النسخة الأولى

- **ثلاثة أنواع بنود:** ملاحظة فنية وعمل مطلوب (يضيفهما الاستشاري)، وطلب فحص (يضيفه المقاول).
- **أربع حالات فقط** تجيب على سؤال "الكرة عند من؟":
  - مفتوح ← عند المقاول.
  - بانتظار المراجعة ← عند الاستشاري.
  - متوقف (بسبب).
  - مغلق.
- **الصلاحيات مطبّقة داخل قاعدة البيانات:**
  - المقاول لا يستطيع الإغلاق، ولا تعديل الملاحظة الأصلية، ولا حذف أي شيء.
  - الإعادة والإيقاف وإعادة الفتح تتطلب سببًا.
- **سجل زمني لكل بند:** من أضاف ومن رد ومن عدّل ومتى، مع صور قبل المعالجة وبعدها.
- **مزامنة لحظية** بين الطرفين بدون تحديث الصفحة.
- **العمل بدون إنترنت:** البند والرد والصور تُحفظ على الجهاز وتُرسل تلقائيًا عند عودة الاتصال.
- **ضغط الصور قبل الرفع:** حوالي 200–300 KB بدل 3–5 MB.
- **مؤشرات سريعة تعمل كفلاتر:** عليّ الآن · متأخر · حرج · جديد. والتأخير يُحسب تلقائيًا من تاريخ الاستحقاق.
- **تصدير** Excel (CSV) وطباعة/PDF للبنود المعروضة.

## التشغيل لأول مرة (حوالي 15 دقيقة)

### 1) Supabase
1. أنشئ مشروعًا مجانيًا في [supabase.com](https://supabase.com).
2. افتح **SQL Editor ← New query**، والصق محتوى الملف `supabase/schema.sql` كاملًا، ثم اضغط **Run**.
3. من **Authentication ← Users ← Add user** أنشئ حسابًا لكل مهندس (بريد + كلمة مرور). فعّل **Auto Confirm User**.
4. ارجع إلى **SQL Editor** وحدد دور كل حساب:
   ```sql
   select admin_add_member('consultant@example.com', 'consultant', 'م. الاسم');
   select admin_add_member('contractor@example.com', 'contractor', 'م. الاسم');
   ```
5. من **Authentication ← Sign In / Providers** أوقف خيار **Allow new users to sign up**، حتى لا ينشئ أحد حسابًا بنفسه.

### 2) ربط الواجهة بقاعدة البيانات
افتح `js/config.js` وضع فيه **Project URL** و **anon public key** من **Project Settings ← API**.
**لا تضع مفتاح service_role في أي ملف.**

### 3) النشر على GitHub Pages
**Settings ← Pages ← Source: Deploy from a branch ← main / (root)**، ثم انتظر دقيقة.
يصبح الرابط: `https://<اسم-الحساب>.github.io/jenan/`

### 4) التثبيت على الجوال
- **iPhone:** افتح الرابط في Safari ← زر المشاركة ← إضافة إلى الشاشة الرئيسية.
- **Android:** افتح الرابط في Chrome ← القائمة ← تثبيت التطبيق.

> **بدون إعداد Supabase** تعمل المنصة في **الوضع التجريبي**: البيانات على الجهاز نفسه فقط. افتح تبويبين، أحدهما بدور الاستشاري والآخر بدور المقاول، لتجربة المزامنة.

## ملاحظات تشغيلية مهمة

- **توقف الخطة المجانية:** مشروع Supabase المجاني يتوقف بعد أسبوع بدون نشاط. الاستخدام اليومي يمنع ذلك. وعند التشغيل الفعلي يُنصح بخطة Pro (حوالي 25$ شهريًا) للنسخ الاحتياطي اليومي وإلغاء التوقف.
- **النسخ الاحتياطي على الخطة المجانية:** صدّر Excel أسبوعيًا من **حسابي ← تصدير Excel** مع اختيار تصفية "الكل". أو صدّر الجداول من **Supabase ← Table Editor**.
- **ظهور التحديثات:** المنصة تحفظ ملفاتها على الجهاز لتعمل بدون إنترنت، لذلك يظهر أي تحديث للواجهة **عند فتحها للمرة الثانية** بعد النشر.
- **السعة:** 1 GB للصور يتسع لحوالي 4000 صورة بعد الضغط.

## هيكل الملفات

```
index.html              الصفحة
css/app.css             التصميم (جوال + كمبيوتر + طباعة)
js/config.js            بيانات Supabase
js/data.js              الاتصال بقاعدة البيانات + طابور العمل بدون إنترنت + ضغط الصور
js/app.js               الواجهة
sw.js                   حفظ ملفات المنصة على الجهاز
supabase/schema.sql     الجداول والصلاحيات والإجراءات
```

## المراحل القادمة

1. **مراحل العمل:** خطوات متتابعة ونقاط توقف (Hold Points) لا تُعتمد المرحلة دونها، مع ربط البنود بالمرحلة.
2. **إشعارات على الجوال** حتى والمنصة مغلقة.
3. **تقرير PDF بالصور** قبل المعالجة وبعدها لكل بند.
4. **مشاريع متعددة:** قاعدة البيانات جاهزة لها من الآن.
